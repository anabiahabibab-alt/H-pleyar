# H Player

All-in-one Android music & video player built with Kotlin and Jetpack Compose.

## Automatic APK Builds & Public Download

Every time code is pushed to GitHub, the **Build & Release APK** GitHub Actions workflow automatically builds `H-Player.apk` and publishes it so anyone can download and install it:

1. **Public Download (No GitHub login required):**
   - Open the **Releases** section on the right side of this repository (or go to `releases/latest`).
   - Download **`H-Player.apk`** from **Assets**.
2. **Workflow Artifact (GitHub Actions tab):**
   - Go to the **Actions** tab → select the latest **Build & Release APK** run → download **`H-Player-APK`**.
